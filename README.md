# พยากรณ์ PM2.5 เชียงใหม่ล่วงหน้า 1-3 วัน

เว็บแอป (Streamlit) พยากรณ์ค่า PM2.5 รายวันของเชียงใหม่ล่วงหน้า 1-3 วัน ด้วยโมเดล Gradient Boosting
จากข้อมูลย้อนหลังและค่าพยากรณ์อากาศ แสดงระดับ AQI ตามเกณฑ์ไทย พร้อมช่วงความคลาดเคลื่อนปกติ

## วิธีทำงาน

1. ดึงข้อมูล PM2.5 (แบบจำลอง CAMS) และสภาพอากาศย้อนหลังตั้งแต่ปี 2023 จาก [Open-Meteo](https://open-meteo.com)
2. สร้างฟีเจอร์: ค่า PM2.5 ย้อนหลัง, ค่าเฉลี่ยเคลื่อนที่, ฤดูกาล, สภาพอากาศ และ
   **ค่าพยากรณ์อากาศล่วงหน้า** (ลม ฝน ความสูงชั้นผสมอากาศ ฯลฯ)
3. เทรนโมเดลแยกสำหรับ +1, +2, +3 วัน โดยให้โมเดลเรียนรู้ "ส่วนต่างจากค่าวันนี้" แทนค่าสัมบูรณ์
4. ตอนเปิดแอป ดึงข้อมูลล่าสุด เทรนโมเดล (แคช 6 ชั่วโมง) แล้วพยากรณ์

## ผลทดสอบ

ทดสอบแบบ walk-forward ปี 2024, 2025, 2026 (เทรนด้วยข้อมูลก่อนปีที่ทดสอบเท่านั้น)
เทียบกับ baseline คือการเดาว่าเท่ากับวันนี้

| ล่วงหน้า | MAE โมเดล | MAE baseline | ดีขึ้น |
|---|---|---|---|
| +1 วัน | 3.83 | 4.05 | ~5% |
| +2 วัน | 4.95 | 5.64 | ~12% |
| +3 วัน | 5.32 | 6.32 | ~16% |

หน่วย µg/m³ ช่วงหน้าแล้ง (ม.ค.-เม.ย.) โมเดลชนะ baseline ชัดเจนที่ +3 วัน
ส่วน +1 วันยังไม่ชนะ baseline

## รันบนเครื่อง

```bash
pip install -r requirements.txt
streamlit run app.py
```

## เผยแพร่ฟรีบน Streamlit Community Cloud

1. อัปโหลดโฟลเดอร์นี้ (`app.py`, `requirements.txt`, `README.md`) ขึ้น GitHub repo
2. เข้า [share.streamlit.io](https://share.streamlit.io) ล็อกอินด้วย GitHub
3. กด **Create app** เลือก repo, branch `main`, ไฟล์หลัก `app.py` แล้วกด Deploy
4. รอประมาณ 2-3 นาที จะได้ลิงก์เว็บไว้แชร์

## ข้อจำกัด

- PM2.5 มาจากแบบจำลอง CAMS ไม่ใช่เครื่องวัดจากสถานีจริง อาจต่างจากค่าที่เห็นในแอปอื่น
- ยังไม่มีข้อมูลจุดความร้อนไฟป่า ช่วงหน้าแล้งความคลาดเคลื่อนจึงสูงกว่าช่วงอื่น
- ค่าพยากรณ์อากาศย้อนหลังที่ใช้เทรนเป็นค่าที่ใกล้วันจริง ไม่ใช่พยากรณ์ล่วงหน้า 3 วันจริง
  ผลทดสอบจึงอาจดีกว่าการใช้งานจริงเล็กน้อย
- ใช้เพื่อการศึกษาเท่านั้น ไม่ใช่ข้อมูลทางการ ค่าตรวจวัดอย่างเป็นทางการดูที่ [Air4Thai](http://air4thai.pcd.go.th)
